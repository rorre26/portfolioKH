# Интерактивное резюме Арифа Хадикова

[Открыть сайт](https://rorre26.github.io/portfolioKH/)

Автоматизирую и оптимизирую процессы в течение четырёх лет.

Сайт на React, TypeScript и Vite: опыт работы, компетенции, примеры личного вклада, интерактивная карта WMS и скачиваемое резюме в PDF. Учитываются мобильные экраны, управление с клавиатуры и предпочтение уменьшения анимации.

## Разработка

Исходный React-проект находится в `react-source.zip`. Архив содержит исходники, закреплённые зависимости, общие данные резюме, компоненты, ресурсы и лицензии; служебные файлы и зависимости в него не включены.

Распакуйте архив и выполните в папке проекта:

```sh
pnpm install --frozen-lockfile
pnpm run build
pnpm run preview
```

Для разработки используйте `pnpm run dev`. Предпросмотр доступен на `http://127.0.0.1:4173/`.

## Размещение

GitHub Pages публикует готовую сборку из корня ветки `main`. Файлы `index.html` и `assets/` созданы сборкой Vite с предварительной разметкой страницы; React подключает интерактивность после загрузки. Относительные адреса ресурсов поддерживают размещение в `/portfolioKH/`. Файл `.nojekyll` отключает обработку сборки Jekyll.

После изменений пересоберите проект, обновите исходный архив и перенесите содержимое `dist/` в корень репозитория. PDF для скачивания находится в `public/assets/arif-khadikov-resume.pdf`; профессиональные сведения — в `src/resume.json`. Генератор PDF требует Python, ReportLab, pypdf и DejaVu Sans; каталог шрифтов задаётся через `RESUME_FONT_DIR`.

Использованы адаптированные компоненты [SmoothUI](https://github.com/educlopez/smoothui) по лицензии MIT. Исходники и лицензия сохранены в архиве (`vendor/smoothui/`); копия лицензии размещена в `assets/smoothui-license.txt`. Rubik распространяется по лицензии из `assets/font-license.txt`.
